================================================================================
IF LOGIN STILL FAILS
================================================================================

SCENARIO A: "These credentials do not match our records"
--------------------------------------------------------------------------------
This means:
1. User doesn't exist in database, OR
2. Password is incorrect, OR
3. Email is wrong

To check if user exists:
php artisan tinker
>>> \App\User::where('email', 'youremail@example.com')->first();

If user exists, you'll see user details.
If NULL, the user doesn't exist.


SCENARIO B: Create a new test user
--------------------------------------------------------------------------------
php artisan tinker
>>> $user = new \App\User();
>>> $user->name = 'Test User';
>>> $user->email = 'test@test.com';
>>> $user->password = bcrypt('password123');
>>> $user->save();
>>> exit

Then try logging in with:
Email: test@test.com
Password: password123


SCENARIO C: Reset existing user password
--------------------------------------------------------------------------------
php artisan tinker
>>> $user = \App\User::where('email', 'youremail@example.com')->first();
>>> $user->password = bcrypt('newpassword');
>>> $user->save();
>>> exit
