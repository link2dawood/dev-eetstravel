TEMPLATE FOR FIXING PAGES
================================================================================

Step 1: Replace Layout
----------------------
OLD: @extends('scaffold-interface.layouts.app')
NEW: @extends('scaffold-interface.layouts.tabler-app')

Step 2: Replace Box Classes
---------------------------
OLD: <div class="box box-primary">
     <div class="box-header">...</div>
     <div class="box-body">...</div>
     </div>
     
NEW: <div class="card">
     <div class="card-header">...</div>
     <div class="card-body">...</div>
     </div>

Step 3: Update Page Header
---------------------------
Add:
<div class="page-header d-print-none">
    <div class="row g-2 align-items-center">
        <div class="col">
            <div class="page-pretitle">Section Name</div>
            <h2 class="page-title">
                <i class="ti ti-icon"></i> Page Title
            </h2>
        </div>
        <div class="col-auto ms-auto">
            <div class="btn-list">
                <!-- Action buttons -->
            </div>
        </div>
    </div>
</div>

Step 4: Update Forms
---------------------
OLD: <div class="form-group">
NEW: <div class="mb-3">

OLD: <label>Field</label>
NEW: <label class="form-label">Field</label>

Step 5: Update Tables
----------------------
OLD: <table class="table table-bordered">
NEW: <table class="table card-table table-vcenter">

Step 6: Update Modals
----------------------
OLD: data-dismiss="modal"
NEW: data-bs-dismiss="modal"

OLD: data-toggle="modal"
NEW: data-bs-toggle="modal"

OLD: <button class="close" data-dismiss="modal">×</button>
NEW: <button class="btn-close" data-bs-dismiss="modal"></button>

Step 7: Update Icons
---------------------
OLD: <i class="fa fa-edit"></i>
NEW: <i class="ti ti-edit"></i>

Step 8: Update Buttons
-----------------------
OLD: <button class="btn btn-success">
NEW: <button class="btn btn-primary">

Step 9: Add Responsive Classes
-------------------------------
Forms: col-12 col-md-6 col-lg-4
Tables: table-responsive
Grids: row g-2, row g-3

Step 10: Test
-------------
- Desktop view
- Tablet view (768px)
- Mobile view (375px)
- All interactive elements
