TROUBLESHOOTING:
================================================================================

If table doesn't load:
1. Check console for errors
2. Verify DataTables files load (Network tab)
3. Check column count (should be 7)
4. Verify jQuery version (3.6.0+)
5. Check AJAX response format

If columns are wrong:
1. Verify table has 7 <th> elements
2. Check DataTables columns config (7 items)
3. Ensure responsive: true is set
4. Check responsivePriority values

If not responsive:
1. Verify responsive CSS loaded
2. Check responsive JS loaded
3. Test browser width
4. Check DevTools responsive mode

If Bootstrap styling is off:
1. Verify Bootstrap 5 plugin loaded
2. Check DOM structure
3. Clear browser cache
4. Check for CSS conflicts
